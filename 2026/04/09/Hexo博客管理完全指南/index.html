3. 404 页面配置

在 Hexo 中，404 页面的配置非常简单：

  1. 在 source 目录下创建 404.md 文件
  2. 执行 npm run build 命令生成 404.html
  3. 部署到 GitHub Pages，GitHub Pages 会自动处理 404 页面的显示

七、完整工作流

日常管理工作流

  1. 创建新文章：npx hexo new "文章标题"
  2. 编辑文章：在 source/_posts 目录下编辑文章
  3. 预览效果：npm run server，访问 http://localhost:4000
  4. 清理缓存：npm run clean
  5. 生成静态文件：npm run build
  6. 部署到 GitHub：npm run deploy
  7. 更新源码：git add . && git commit -m "更新内容" && git push

主题更换工作流

  1. 安装主题：npm install hexo-theme-next
  2. 复制主题文件：xcopy node_modules\hexo-theme-next themes\next /E /I
  3. 修改配置：修改 _config.yml 文件，设置 theme: next
  4. 清理缓存：npm run clean
  5. 生成静态文件：npm run build
  6. 部署到 GitHub：npm run deploy
